Installing the Street Sign Capture tool

This is a small add-on ("extension") for the Google Chrome web browser. It adds a "Capture Sign" button while you're browsing street imagery, so you can flag damaged street signs as you find them. You don't need any technical background to install or use it — just follow the steps below in order.

Before you start, you'll need:

  • Google Chrome (not Edge, Firefox, or Safari — this only works in Chrome)
  • The extension file, street-sign-capture-extension.zip, sent to you by the project maintainer
  • Your own login for Cyclomedia Street Smart (this tool works alongside Street Smart, but doesn't give you access to it — that's separate)

Step 1: Save and unzip the file

  1. Save street-sign-capture-extension.zip somewhere you'll remember, like your Desktop or Downloads folder.
  2. Find the file and unzip it:
  3. Windows: Right-click the file → Extract All... → Extract.
  4. Mac: Double-click the file. A new folder with the same name appears next to it.
  5. You should now have a folder (not a .zip file) containing files named manifest.json, content.js, and a few others. Keep this folder where it is — don't delete it after installing, Chrome needs to keep reading from it.

Step 2: Load it into Chrome

  1. Open Chrome.
  2. Click into the address bar at the top, type chrome://extensions, and press Enter.
  3. In the top-right corner of that page, find the Developer mode switch and turn it on. (This just lets Chrome load extensions that aren't from the Chrome Web Store — perfectly safe.)
  4. Three new buttons will appear. Click Load unpacked.
  5. A file-picker window opens. Navigate to and select the folder you unzipped in Step 1 (the one containing manifest.json), then click Select Folder.
  6. A card titled "Street Sign Capture" should now appear on the extensions page. That means it's installed.

Step 3: Pin the icon (optional, but handy)

  1. In Chrome's toolbar (top-right, near the address bar), click the puzzle piece icon (Extensions).
  2. Find Street Sign Capture in the list and click the pin icon next to it. Its icon now stays visible in the toolbar, so you can quickly check how many signs you've captured.

Step 4: Try it

  1. Go to Cyclomedia Street Smart (or Google Street View) and open any location.
  2. Within a second or two, you should see:
  3. A small floating "📷 Capture Sign" button
  4. A small compass in the corner of the screen
  5. If you see those, installation worked — move on to USER_GUIDE.html for how to actually capture a sign.

If something's not showing up

  • Nothing appears at all: refresh the page (F5). The extension has to load fresh on each new page/site.
  • You edited or replaced the extension folder after installing: go back to chrome://extensions, find the Street Sign Capture card, and click the reload icon (⟳) on it — then also refresh the page you're viewing Street Smart on. Both steps are needed; reloading the extension alone doesn't update a page that's already open.
  • The Capture button seems stuck on "Capturing..." forever: this is the same fix as above — reload the extension in chrome://extensions, then refresh the Street Smart tab.
  • Still stuck: contact the project maintainer with a screenshot of what you're seeing.
